name: Mkenya Shop background motion
description: Ambient background color movement and accessibility expectations for the storefront.
---

The user wants Mkenya Shop background colors to shift continuously but almost imperceptibly.

**Why:** The user explicitly asked for all backgrounds to change gradually without the effect being noticeable.

**How to apply:** Keep the drift slow and low-amplitude, preserve text contrast, and disable it when reduced motion is preferred.
